譲れないルール

人間が主権を持つのは二つ

💡 IDEA

何を問う価値があるか、意味は何か、倫理的か。候補はエージェントが鍛造し、ロックは人間がする。

📊 DATA

実在・IRB承認・機械起源ではない。生の臨床データはローカルのまま gitignore。数値の捏造はしない。

ライフサイクル

Discoveryから査読対応まで、ゲート付き

  1. −1Discovery質問鍛造 · 新規性 · デザイン · 事前登録
  2. 1–2.5文献 → アウトライン → 表・図本文より先に展示物を設計
  3. 3–5執筆 → ヒューマナイズ → 文献日英AIパターン除去 · DOI検証
  4. 6–6.5品質 + 敵対的レビュー中心主張をレッドチーム
  5. 7–10投稿 · 改訂 · 受理 · リジェクト再投稿
